# Portfólio — Yara Fabricia

Site de portfólio de UX/UI design, com os cases completos (pesquisa, decisões de design e testes de usabilidade).

## Projetos

- **Arena Airsoft** — app de organização de partidas de airsoft. Case completo: pesquisa com usuários reais, arquitetura de informação, UI e duas rodadas de teste de usabilidade. ([ver case](https://arenaairsoftapp.vercel.app/cases/arena-airsoft.html))
- **Traço e Barro** — e-commerce de decoração artesanal. Case completo: personas, wireframes, protótipo navegável e identidade visual "Terra & Argila". ([ver case](https://tracoebarroloja.vercel.app/case.html))

## Stack

HTML e CSS puro, sem framework. Deploy automático via [Vercel](https://vercel.com), a partir deste repositório.
